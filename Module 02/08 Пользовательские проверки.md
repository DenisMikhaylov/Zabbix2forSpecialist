### **Практическая работа**

### **Задача 1: Внешние проверки с использованием ExternalScripts**

1. Подключиться по SSH к zabbix Server

2. Получить текущий путь для внешних скриптов

```
zabbix_server --help | grep ExternalScripts
```

3. Настройка внешних скриптов

```
nano /etc/zabbix/zabbix_server.conf
```
4. Изменить следующе строки
```
...
Timeout=30
...
ExternalScripts=/etc/zabbix/externalscripts
...
```
4.1 Перезапустить zabbix server
```
systemctl restart zabbix-server.service
```
5. Создание директории для внешних скриптов

```
mkdir /etc/zabbix/externalscripts
```
6. Создание первого скрипта 
Скрипт для получение среднего значение пинга
```
nano /etc/zabbix/externalscripts/ping_avg.sh
```
```
#!/bin/sh
ping -c"$1" "$2" | tail -n1 | cut -d'/' -f5
```
6.1. Добавление прав на скрипт
```
chmod +x /etc/zabbix/externalscripts/ping_avg.sh
```
6.2. Проверка работы скрипта
```
/etc/zabbix/externalscripts/ping_avg.sh 3 ya.ru
```

6.3. Настройка приминения первого скрипта
```
Data collection->Hosts->ya.ru или google.com
  Items
    Name: Ping AVG
    Type: External Check
    Key: ping_avg.sh[3,"{HOST.CONN}"]
    Type of information: Numeric (float)
    Units: ms
```


7. Создание третьего скрипта

Использование утилиты nmap

7.1. Установить на сервер
```
apt install nmap
```
7.2. Создание скрипта
```
nano /etc/zabbix/externalscripts/detect_host_nmap.sh
```
```
#!/bin/sh
sudo /usr/bin/nmap -O $1 | grep -v 'Starting Nmap\|Host is up\|Nmap done'
```
8.3. Выдача прав на скрипт
```
chmod +x /etc/zabbix/externalscripts/detect_host_nmap.sh
```
7.4. Настройка сбора данных
```
Data collection->Hosts->Gate
  Items
    Name: Detect host operating system by nmap
    Type: External Check
    Key: detect_host_nmap.sh["{HOST.CONN}"]
    Type of information: Text
```

8. Создание проверок по средствам trapper

8.1 Переключиться в веб интерфейс Zabbix

8.2. Создание элемента
```
Data collection->Hosts->server->Items
  Name: my item
    Type: Zabbix trapper
    Key:  my.item
    Allowed hosts: 127.0.0.1, 192.168.10.0/24
```
8.3. Подключиться к Server по SSH

8.4. Установка Zabbix sender на Server

```
apt install zabbix-sender
```
8.5. Отправка данных на Item
```
zabbix_sender -z 192.168.10.10 -p 10051 -s server -k my.item -o 1
```


### **10. Создание проверок по средствам UserParameter**

10.1. Переключаемся на gate

10.2. Настройка файла конфигурации для Zabbix Agent

```
nano /etc/zabbix/zabbix_agentd.d/my.linux.disk.discovery.conf
```
10.3. Добавить строку в файл конфигурации
```
UserParameter=my.disks.discovery,/bin/lsblk -dJ | /bin/sed -e 's/blockdevices/data/' -e 's/name/{#NAME}/g' -e 's/type/{#TYPE}/g'
```

10.4. Gереключаемся на Server
10.5. Проверяем работу нового ключа

```
zabbix_get -s 192.168.10.1 -k my.disks.discovery 
```
10.6. Установка дополнително ПО для удобсва чтения

```
apt install jq
```
Повторная проверка 
```
zabbix_get -s 192.168.10.1 -k my.disks.discovery | jq
```

11. Настройка монитринга DHCP на Gate

11.1. Переключиться на gate

11.2. Установка средст мониторинга 
```
apt install dhcpd-pools
```

11.3. Получение информации о работе DHCP 
```
dhcpd-pools -l /var/lib/dhcp/dhcpd.leases -c /etc/dhcp/dhcpd.conf
```

11.4. Создание скрипта для мониторинга DHCP

```
nano /usr/local/bin/dhcp_stat.sh
```
```
#!/bin/sh

CMD='/usr/bin/dhcpd-pools -l /var/lib/dhcp/dhcpd.leases -c /etc/dhcp/dhcpd.conf -f c | grep 192.168.'
MAX=`eval $CMD | cut -d'"' -f8`
CUR=`eval $CMD | cut -d'"' -f10`

eval RES=\$$1

echo $RES
```
11.5. Выдача прав на скрипт
```
chmod +x /usr/local/bin/dhcp_stat.sh
```
11.6. Проверка отрабатывания скрипта
```
/usr/local/bin/dhcp_stat.sh MAX
```
```
/usr/local/bin/dhcp_stat.sh CUR
```
11.7. Настройка Zabbix agent для сборки статистики по DHCP

```
nano /etc/zabbix/zabbix_agentd.d/dhcp_stat.conf
```

```
UserParameter=dhcp.stat[*],/usr/local/bin/dhcp_stat.sh $1
```

11.8. Переключаемся на server и проверяем возврат информации
```
zabbix_get -s 192.168.10.1 -k dhcp.stat[CUR]
```
```
zabbix_get -s 192.168.10.1 -k dhcp.stat[MAX]
```


12. Настройка Вычисляемых элементов

12.1. Открыть веб консоль Zabbix

12.2. Настройка мониторинга DHCP

Data collection->Hosts->gate->Items
  Name: DHCP stat CUR
    Type: Zabbix agent

## 3.3. Сбор данных. SSH/Telnet-мониторинг

### Задание 3.3.1. SSH-проверка свободного места на `/`
Реализуйте элемент данных типа **SSH agent** для `debian12`.
- **Key:** `ssh.run[disk_free_root,<IP_debian12>,,UTF-8]`
- **Authentication method:** Password или Public key.
- **User name:** пользователь Debian 12 с правом входа по SSH.
- **Executed script:** `df -h / | awk 'NR==2 {print $4}'`
- **Type of information:** Text.
- **Проверка:** значение появилось в Latest data и соответствует выводу команды на `debian12`.

### Задание 3.3.2. SSH-проверка количества процессов `nginx`
Реализуйте элемент данных типа **SSH agent**.
- **Key:** `ssh.run[nginx_proc,<IP_debian12>,,UTF-8]`
- **Executed script:** `pgrep -c nginx || echo 0`
- **Type of information:** Numeric (unsigned).
- **Проверка:** в Latest data отображается число; при остановленном nginx возвращается `0`.

### Задание 3.3.3. SSH-проверка версии ядра
Реализуйте элемент данных типа **SSH agent**.
- **Key:** `ssh.run[kernel_ver,<IP_debian12>,,UTF-8]`
- **Executed script:** `uname -r`
- **Type of information:** Text.
- **Проверка:** значение совпадает с выводом `uname -r` на `debian12`.

### Задание 3.3.4. Telnet-проверка тестового сервиса
Разверните на `debian12` тестовый Telnet-сервис, если он отсутствует, и реализуйте элемент данных типа **Telnet agent**.
- **Key:** `telnet.run[check_telnet,<IP_debian12>,23,UTF-8]`
- **Executed script:** `echo OK`
- **Type of information:** Text.
- **Проверка:** элемент данных получает значение `OK` при доступном Telnet-сервисе; при остановке сервиса элемент становится недоступным/неподдерживаемым.

## 3.5. Сбор данных. Вычисляемые проверки

Тип элементов — **Calculated**. Формулы используют элементы данных хоста `debian12`.

### Задание 3.5.1. Процент свободного места на `/`
Создайте вычисляемый элемент данных.
- **Key:** `calc.free_disk_pct`
- **Formula:** `100*last(//vfs.fs.size[/,free])/last(//vfs.fs.size[/,total])`
- **Type of information:** Numeric (float).
- **Проверка:** значение соответствует проценту свободного места на `/`.

### Задание 3.5.2. Средняя загрузка CPU за 10 минут
Создайте вычисляемый элемент данных.
- **Key:** `calc.avg_load_10m`
- **Formula:** `avg(//system.cpu.load[all,avg1],10m)`
- **Type of information:** Numeric (float).
- **Проверка:** значение изменяется при изменении нагрузки и соответствует среднему за 10 минут.

### Задание 3.5.3. Процент использованной памяти
Создайте вычисляемый элемент данных.
- **Key:** `calc.memory_used_pct`
- **Formula:** `100*(last(//vm.memory.size[total])-last(//vm.memory.size[available]))/last(//vm.memory.size[total])`
- **Type of information:** Numeric (float).
- **Проверка:** значение находится в диапазоне 0–100 и соответствует текущему потреблению памяти.

### Задание 3.5.4. Суммарный сетевой трафик на `eth0`
Создайте вычисляемый элемент данных.
- **Key:** `calc.net_eth0_total`
- **Formula:** `last(//net.if.in[eth0])+last(//net.if.out[eth0])`
- **Type of information:** Numeric (unsigned).
- **Проверка:** значение равно сумме последних значений входящего и исходящего трафика по `eth0`.

## 3.10. Использование командной строки. `zabbix_get`, `zabbix_sender`

### Задание 3.10.1. Запрос нагрузки CPU через `zabbix_get`
На `server` или `debian12` выполните запрос к агенту:
```bash
zabbix_get -s 127.0.0.1 -p 10050 -k "system.cpu.load[all,avg1]"
```
**Результат:** команда возвращает числовое значение нагрузки CPU. Сравните его со значением в Latest data.

### Задание 3.10.2. Проверка пользовательского параметра через `zabbix_get`
Выполните запрос к пользовательскому параметру из раздела 3.9:
```bash
zabbix_get -s 127.0.0.1 -p 10050 -k "custom.disk.usage"
```
**Результат:** команда возвращает процент использования `/`; значение совпадает с Latest data для ключа `custom.disk.usage`.

### Задание 3.10.3. Отправка одиночного значения через `zabbix_sender`
Создайте для хоста `debian12` элемент данных типа **Zabbix trapper** с ключом `custom.metric`, тип Numeric (unsigned). Отправьте значение:
```bash
zabbix_sender -z <IP_server> -s "debian12" -k custom.metric -o 42
```
**Результат:** в ответе `processed: 1; failed: 0`; значение `42` появилось в Latest data для ключа `custom.metric`.

### Задание 3.10.4. Массовая отправка значений из файла через `zabbix_sender`
Создайте файл `data.txt`:
```text
debian12 custom.metric 100
debian12 custom.metric 200
```
Выполните массовую отправку:
```bash
zabbix_sender -z <IP_server> -i data.txt
```
**Результат:** в ответе `processed: 2; failed: 0`; в Latest data отображается последнее отправленное значение `200`.
